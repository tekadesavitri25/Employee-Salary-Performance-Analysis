# Employee Salary & Performance Analysis

## Project Overview

This project analyzes employee salary and performance data to identify patterns and relationships between salary, experience, department, job role, gender, and performance rating.

## Problem Statement

Organizations need to understand salary distribution and employee performance to make better HR and compensation decisions. This project analyzes employee data to identify important salary and performance patterns.

## Dataset Description

The dataset contains 120 employee records and 8 columns:

- Employee_ID
- Age
- Gender
- Department
- Job_Role
- Experience_Years
- Salary
- Performance_Rating

## Key Insights

1. IT department has the highest average salary.
2. Operations department has the lowest average salary.
3. Employees with higher experience generally earn higher salaries.
4. Most employees have performance ratings of 3 or 4.
5. Salary has a strong positive relationship with experience.
6. Performance rating has very little linear relationship with salary.

## Business Recommendations

1. Provide career development and skill-building opportunities to employees so they can progress to higher-paying roles.

2. Review salaries across departments and job roles to ensure compensation is competitive and aligned with experience and responsibilities.

## Conclusion

The analysis shows that employee experience is strongly associated with salary. The Power BI dashboard provides an interactive way to explore employee salary, experience, department, gender, and performance patterns.
