# Employee Salary & Performance Analysis

## Project Overview

This project analyzes employee salary and performance data to identify patterns and relationships between salary, experience, department, job role, and performance rating.

## Objectives

- Analyze employee salary and performance data.
- Clean and prepare the dataset.
- Perform Exploratory Data Analysis (EDA).
- Create meaningful data visualizations.
- Build an interactive Power BI dashboard.
- Generate business insights and recommendations.

## Dataset

The dataset contains 120 employee records with the following columns:

- Employee_ID
- Age
- Gender
- Department
- Job_Role
- Experience_Years
- Salary
- Performance_Rating

## Key Insights

- IT department has the highest average salary.
- Operations department has the lowest average salary.
- Employees with more experience generally earn higher salaries.
- Most employees have performance ratings of 3 or 4.
- Salary has a strong positive relationship with experience.
- Performance rating has very little relationship with salary.

## Business Recommendations

1. Provide career development and skill-building opportunities to employees.
2. Review salaries across departments and job roles to ensure competitive compensation.

## Conclusion

The analysis shows that employee experience is strongly associated with salary. The Power BI dashboard provides an interactive way to explore salary, experience, department, gender, and performance patterns.
